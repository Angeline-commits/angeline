Travel Agent -Destination Availability Tool.

Travel Agent

Tool name: check_destination_availability

This tool handles destination availability check requests by checking package availability.
It accepts two parameters:

  • booking_destination: name of the city to book
  • destination_type: Type of destination. This can be Beach, Mountain ,Wildlife, Desert Heritage, Spiritual or Backwater

If a destination is available, the tool confirms the availability and returns a message. If not, it sends a message with information on the alternate destinations of the same type .
